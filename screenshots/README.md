## Задача 1. Проверка на палиндром

### Задание

Написать функцию, определяющую, является ли последовательность палиндромом.

Примеры работы:

```

> > > is_palindrome([1, 2, 3, 2, 1])
> > > True
> > > is_palindrome('spam')
> > > False

```

**Требование:** решить двумя способами — с рекурсией и без. Глобальные переменные не использовать.

### Описание проделанной работы

1. **Рекурсивная версия** `is_palindrome_recursive`.
   - **База рекурсии:** если длина последовательности `<= 1`, это палиндром (возвращаем `True`).
   - **Шаг рекурсии:** сравниваем первый и последний элементы (`seq[0]` и `seq[-1]`). Если они не равны — сразу возвращаем `False`. Если равны — вызываем функцию для «внутренности» без крайних элементов (`seq[1:-1]`).
   - Состояние между вызовами не хранится: каждая копия функции работает только со своим срезом.

2. **Итеративная версия** `is_palindrome_iterative`.
   - Используются два указателя: `left` с начала, `right` с конца.
   - Пока `left < right`, сравниваем `seq[left]` и `seq[right]`.
   - При первом несовпадении возвращаем `False`. Если указатели встретились — `True`.

3. Обе версии работают и со списками, и со строками, так как поддерживают индексацию и срезы.

### Код программы

```

def is_palindrome_iterative(seq):
left = 0
right = len(seq) - 1
while left < right:
if seq[left] != seq[right]:
return False
left += 1
right -= 1
return True
print(is_palindrome_iterative("шалаш"))

```

```

def is_palindrome_recursive(seq):
if len(seq) <= 1:
return True
if seq[0] != seq[-1]:
return False
return is_palindrome_recursive(seq[1:-1])
print(is_palindrome_recursive("шалаш"))

```

### Результат работы

```

True
True

```

## Задача 2. Последовательность x_i = x_{i-1} + x_{i-3}

### Задание

Написать функцию для вычисления `x_i = x_{i-1} + x_{i-3}`, где `x_1 = x_2 = x_3 = 1`.

**Требование:** решить двумя способами — с рекурсией и без. Глобальные переменные не использовать.

### Описание проделанной работы

1. **Итеративная версия** `x_iterative`.
   - Используются три локальные переменные `a, b, c`, соответствующие трём последним значениям (`x_{i-3}, x_{i-2}, x_{i-1}`).
   - На каждом шаге сдвиг: `a, b, c = b, c, a + c`. Новое значение `c` равно сумме бывших `a` и `c` (что соответствует `x_{i-1} + x_{i-3}`).
   - Состояние хранится в локальных переменных, глобальные переменные не используются.

2. **Рекурсивная версия** `x_recursive`.
   - **База рекурсии:** `x_1 = x_2 = x_3 = 1`. Для `n <= 3` возвращаем `1`.
   - **Шаг рекурсии:** `x_n = x_{n-1} + x_{n-3}` — два рекурсивных вызова.
   - Есть защита: при `n < 1` выбрасывается `ValueError`.

**Сложность:**
- рекурсивная версия — экспоненциальная (из-за повторных вычислений);
- итеративная версия — линейная (`O(n)` времени, `O(1)` памяти).

### Код программы

```

def x_iterative(n):
if n < 1:
raise ValueError('n должно быть >= 1')
if n <= 3:
return 1

a, b, c = 1, 1, 1
for _ in range(4, n + 1):
a, b, c = b, c, a + c
return c
print(x_iterative(12))

```

```

def x_recursive(n: int) -> int:
if n < 1:
raise ValueError('n должно быть >= 1')
if n <= 3:
return 1
return x_recursive(n - 1) + x_recursive(n - 3)
print(x_recursive(12))

```

```

41

```
